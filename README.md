# LarkMate

LarkMate 是一个以飞书用户身份工作的 CLI。它使用网页登录 Cookie，帮助 AI 助手和用户操作个人可访问的飞书信息。

## 安装

### 让 AI 安装

把下面的提示词发给有本机终端访问能力的 AI 助手：

```text
请按照 https://raw.githubusercontent.com/NWYLZW/larkmate/main/docs/ai-install.md 帮我安装并使用 LarkMate。
```

### 自己动手安装

需要 Node.js 20 或更新版本。运行以下命令，按提示选择要安装 Skill 的 AI 助手：

```sh
npm install -g larkmate --registry=https://registry.npmjs.org/
npx --registry=https://registry.npmjs.org/ skills add NWYLZW/larkmate --skill larkmate -g
```

登录配置和源码安装步骤见 [快速安装](INSTALL.md)。

## 功能清单

已勾选表示已实现，未勾选表示暂不支持；具体使用仍受当前用户权限限制。

- 会话
  - [x] 搜索用户、机器人和群聊
  - [x] 查询收件箱、已完成和收纳中的会话（分页）
  - [x] 打开或创建私聊
  - [x] 创建群聊、查询会话信息
  - [x] 查询、置顶和取消置顶会话
  - [x] 查询、标记和取消标记会话
  - [x] 标记已读或未读、设置免打扰
  - [x] 移入或移出已完成、会话收纳
  - [x] 创建、重命名和删除标签，管理手动标签下的会话
  - [ ] 修改自动规则标签的会话成员
- 消息
  - [x] 分页读取指定会话的历史消息
  - [x] 在已扫描的历史消息中按关键词、发送者和时间筛选
  - [x] 按会话、发送者和时间范围分页导出消息到本地文件
  - [x] 读取文本、富文本及部分图片和文件元数据
  - [x] 发送文本、引用回复、@ 用户或机器人、发送文件
  - [ ] 全局搜索历史消息
  - [ ] 编辑或撤回消息
  - [ ] 转发或收藏消息
  - [ ] 发送图片消息、下载图片或附件
  - [ ] 给消息添加表情回应
  - [ ] 获取消息链接
- 群聊
  - [x] 查询群信息和成员
  - [x] 修改群名称和介绍、解散群聊
  - [x] 邀请成员和机器人
  - [x] 查询和设置机器人的移除限制
  - [ ] 移除成员或退出群聊
- 录制妙记
  - [x] 查询当前用户可访问的录制妙记
  - [x] 导出文字记录，支持说话人和时间戳
  - [x] 查询访问申请条件
  - [x] 申请查看权限
  - [ ] 查询没有录制妙记的历史会议
  - [ ] 读取智能纪要、导出为飞书文档

具体用法和能力边界见 [LarkMate Skill](skills/larkmate/SKILL.md)。
